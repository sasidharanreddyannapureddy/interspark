# API Fetch Project Using Python

This project fetches user data from an online API using the Requests module in Python.  
It parses JSON data and allows users to search/filter results.

---

## Features

- Fetch API data using Requests
- Parse JSON response
- Display formatted user details
- Search/filter users by name
- Beginner-friendly project

---

## Technologies Used

- Python
- Requests Module
- JSON API

---

## API Used

https://jsonplaceholder.typicode.com/users

---

## Installation

Install Requests module:

```bash
py -m pip install requests
```

---

## Run the Project

```bash
py api_project.py
```
